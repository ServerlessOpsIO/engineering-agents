# Documentation

slack-ai-agent / engineering-agents

AWS AgentCore agents for engineering tasks

This component is an AI agent hosted on Amazon Bedrock AgentCore Runtime. The repository holds
the agent's source code, its container image build, its infrastructure and its deployment
workflows.

## Where to start

- **Deploying the agent for the first time:** complete the
  [deployment prerequisites](handbook/03-configuration.md#deployment-prerequisites).
- **Changing the agent:** find the change in [Common tasks](handbook/07-common-tasks.md).
- **Investigating a problem:** follow
  [Find a request](handbook/06-observability.md#find-a-request).
